# Карта полей: парсер → MiniShop3 → шаблоны

Связка данных между экспортом парсера (`parser/5_exporter.py`), полями товара
MiniShop3 (куда мапим в ImpEx3) и плейсхолдерами в шаблонах `cmi-modx`.

## Каталог и товар

| Колонка CSV (экспорт) | Поле MiniShop3 | Плейсхолдер в шаблонах | Где используется |
|-----------------------|----------------|------------------------|------------------|
| `pagetitle`           | pagetitle      | `[[+pagetitle]]` / `[[*pagetitle]]` | плитка, карточка, тайтл |
| `longtitle`           | longtitle      | `[[*longtitle]]`       | `<title>`, OG |
| `description`         | description    | `[[*description]]`     | meta description |
| `content`             | content        | `[[*content]]`         | таб «О товаре» |
| `price`               | price          | `[[+price:msPrice]]`   | цена |
| `old_price`           | old_price      | `[[+old_price:msPrice]]` | старая цена |
| `article`             | article        | `[[+article]]` / `[[*article]]` | артикул |
| `image`               | image          | `[[+image]]` / `[[*image]]` | главное фото |
| `gallery` (через `\|\|`) | галерея (msGallery) | `[[!msGallery]]` → `tpl.galleryThumb` | галерея товара |
| `category`            | parent / дерево | —                      | строится ImpEx3 из пути |
| `brand`               | TV/поле бренда (текст) | `[[+brand]]`       | бренд на плитке/строке |
| `vendor`              | manufacturer (vendor) | фильтр по бренду   | фасет бренда в фильтрах |
| `rating`              | rating         | `[[+rating:cmiStars]]` | звёзды рейтинга |
| `reviews_count`       | count_reviews  | `[[+count_reviews]]`   | счётчик отзывов |
| `option.<ключ>`       | опция MS3 (msOption) | `[[!msProductOptions]]` → `tpl.specRow` | характеристики + фильтры |

> `brand` и `vendor` несут одно и то же значение бренда: `brand` — для прямого
> вывода текстом (`[[+brand]]`), `vendor` — чтобы ImpEx3 завёл производителя
> MiniShop3 (по нему работает фасет фильтра).

## Поля дизайна, которых нет в данных парсера

Деградируют корректно (пустое значение → ветка «иначе»), заполните вручную при
необходимости:

| Плейсхолдер   | Назначение | Источник |
|---------------|------------|----------|
| `[[*remains]]`  | наличие на складе (шт.) | нет в парсере → показывается «Под заказ» |
| `[[*badge]]`    | бейдж `violet:Хит` и т.п. | задаётся вручную |
| `[[*price_b2b]]`| цена для юрлиц | задаётся вручную |
| «В комплекте»   | блок комплектации | статичный, правится в `product.tpl` |

## Опции и фильтрация (MiniShop3)

1. Парсер выгружает характеристики как колонки `option.<ключ>` (см.
   `5_exporter.py`), значения — текст; мультизначения через `||`.
2. ImpEx3 создаёт по ним опции MiniShop3 (`msOption` / `msOptionGroup`).
3. В админке MS3 опцию помечаем фильтруемой и привязываем к категориям.
4. В `catalog.tpl` фасеты перечислены как `option|<ключ>` (плюс `ms|vendor`,
   `ms|price`). Набор опций у категорий разный — добавляйте нужные `option|...`
   под конкретный раздел.

> Имена сниппетов `msProducts` / `msGallery` / `msProductOptions` / `msCart`
> совместимы с miniShop2 по названию. Фильтр (`mFilter2`) и поиск (`mSearch2`)
> сверьте с версиями, выпущенными для MiniShop3.
