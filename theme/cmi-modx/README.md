# ЦМИ — шаблоны для MODX Revolution 3 + miniShop2

Пакет вёрстки интернет-магазина «Центр Музыкальных Инструментов» в формате
**серверных шаблонов и чанков MODX** с плейсхолдерами вызовов сниппетов
(miniShop2, pdoTools, mSearch2/mFilter2). Это не статичный HTML — это заготовки,
которые подключаются к CMS и наполняются данными каталога.

> Стек по ТЗ: MODX 3.x · miniShop2 · pdoTools · mSearch2 · mFilter2.
> Все решения совместимы с MODX 3.

## Установка

1. **Залить ассеты.** Скопируйте `assets/template/` в `assets/template/` на сервере
   (или в namespace вашего шаблона). В `cmi.css` иконки Tabler и шрифт Inter
   подключаются с CDN — при необходимости разместите локально.
2. **Шаблоны.** Для каждого файла из `templates/` создайте Шаблон (Элементы →
   Шаблоны) и вставьте содержимое. Обёртка документа (head/шапка/подвал) вынесена
   в чанки `doc_head` и `doc_foot` — в MODX шаблон не наследует другой шаблон,
   поэтому каждый шаблон страницы сам включает `[[$doc_head]]` … `[[$doc_foot]]`
   вокруг своей разметки. `base.tpl` — для простых страниц (контент из ресурса).
3. **Чанки.** Для каждого файла из `chunks/` создайте Чанк с **тем же именем без
   расширения** (например `tpl.msProductTile`, `doc_head`, `doc_foot`).
4. **Сниппет.** Создайте сниппет `cmiStars` из `snippets/cmiStars.php`.
5. **Ресурсы и ID.** В чанках/шаблонах ID ресурсов проставлены условно
   (`[[~1]]` — главная, `[[~2]]` — каталог, `[[~3]]` — бренды, `[[~12]]` —
   доставка и т.д.). Замените на реальные ID ваших ресурсов. Сводка ниже.
6. **Системные настройки** (Настройки → Системные) для контактов:
   `cmi_phone`, `cmi_phone_raw`, `cmi_hours`, `cmi_email`, `cmi_tg`, `cmi_vk`,
   `cmi_yt`. Либо замените `[[++cmi_*]]` на статические значения.

## Статичные элементы — правка файлами (быстрая замена)

Чтобы не копировать код в админку при каждой правке, делайте шаблоны/чанки/сниппет
**статичными** (привязанными к файлу на сервере). Тогда заменили файл — обновился
элемент.

1. Залейте папку пакета на сервер, например в `core/elements/cmi/` (вне `web`-доступа)
   или в свой namespace.
2. (MODX 3) Включите системную настройку **`static_elements`** = `Да`.
3. При создании Шаблона/Чанка/Сниппета отметьте **«Статичный элемент»** и укажите
   **путь к файлу** (относительно медиа-источника/корня). Примеры:
   - Шаблон `catalog` → `core/elements/cmi/templates/catalog.tpl`
   - Чанк `doc_head` → `core/elements/cmi/chunks/doc_head.tpl`
   - Сниппет `cmiStars` → `core/elements/cmi/snippets/cmiStars.php`
4. Имя элемента в MODX = как в коде (`tpl.msProductTile`, `doc_head` и т.д.),
   расширение `.tpl` в имени не пишется.

Дальнейшие правки витрины: меняете файл в репозитории → `git pull` на сервере →
изменения сразу подхватываются (кэш элементов очистите при необходимости).

> Альтернатива без статики: импортировать элементы можно скопом через пакеты
> вроде Gitify / ContentBlocks-экспорта, но для нашего объёма проще статичные файлы.

## Поля товара (miniShop2)

Стандартные используются напрямую: `pagetitle`, `uri`, `price`, `old_price`,
`image`, `content`, `introtext`, `article`, `rating`, `count_reviews`, `vendor`.

**Доп. поля по ТЗ** — заведите как доп. поля товара miniShop2 или TV:

| Поле          | Назначение                          |
|---------------|-------------------------------------|
| `article`     | Внутренний артикул магазина         |
| `price_b2b`   | Цена для юрлиц (роль «Партнёр»)      |
| `remains`     | Наличие на собственном складе (шт.) |
| `vendor`      | Бренд                               |
| `badge`       | Бейдж вида `violet:Хит`, `sale:−12%`, `success:Новинка` |
| `hit`         | Флаг «Хит продаж» (1/0) для главной  |

Бейдж парсится фильтром `:split`: `[[+badge:split=`:`:0]]` → цвет
(`violet`/`sale`/`success`/`warning`/`neutral`), `:1` → текст.

## Ключевые вызовы сниппетов (уже расставлены)

- **Меню каталога:** `[[!pdoMenu? &parents=`2` &level=`1` &tpl=`tpl.navLink`]]`
- **Хлебные крошки:** `[[!pdoCrumbs? &tpl=`tpl.crumbLink` &tplCurrent=`tpl.crumbCurrent`]]`
- **Товары раздела:** `[[!msProducts? &parents=`[[*id]]` &limit=`12` &tpl=`tpl.msProductTile`]]`
- **Фильтры:** `[[!mFilter2? &parents=`[[*id]]` …]]` (поля: категория, бренд, цена, материал)
- **Поиск:** форма mSearch2 в шапке (`name="query"`, action — ресурс выдачи; задайте `mse2_results_id`)
- **Галерея:** `[[!msGallery? &tpl=`tpl.galleryThumb`]]`
- **Корзина:** `[[!msCart? &tpl=`tpl.msCartRow`]]`, счётчик — `&tpl=`tpl.msMiniCartCount``
- **Оформление:** `[[!msOrder]]` (онлайн-оплаты нет — заказ уходит менеджеру; статусы: новый/в обработке/подтверждён/отправлен/завершён/отменён)
- **Авторизация:** `[[!ifLoggedin]]` (гость → Вход/Регистрация, иначе Профиль; для юрлиц — `:isMemberOf=`Партнёр``)
- **Рейтинг:** `[[+rating:cmiStars]]`

> Создайте недостающие мелкие чанки под ваши сниппеты при необходимости:
> `tpl.msMiniCartCount` (вернуть только число товаров), обёртки mFilter2
> (`tpl.mfilterOuter`, `tpl.mfilterCheckbox`).

## SEO (по ТЗ)

- ЧПУ включается через `friendly_urls` + pdoTools; canonical уже в `base.tpl`.
- `sitemap.xml` — pdoSitemap; `robots.txt` — стандартный.
- Микроразметка — добавьте JSON-LD `Product`/`BreadcrumbList` в `product.tpl`/
  крошки (заготовка Open Graph уже есть в `base.tpl`).
- SEO-тексты категорий — поле `content` раздела (выводится блоком `.sf-seo`).

## Дизайн-система

Весь визуал собран из дизайн-системы ЦМИ (этот проект). `cmi.css` —
сгенерированная сборка: токены (`tokens/*.css`) + стили компонентов +
раскладка витрины (`ui_kits/storefront/storefront.css`). Меняйте исходники
в дизайн-системе и пересобирайте `cmi.css`, чтобы вёрстка и компоненты
оставались единым источником правды.
